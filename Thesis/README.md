# Pearls AQI Predictor — Thesis (LaTeX)

The complete, ready-to-compile LaTeX thesis for the **Pearls AQI Predictor**,
formatted to the same specification as the reference sample, with **35 numbered
figures** (24 images + 11 captioned code excerpts) and **23 tables**. The
compiled output is `main.pdf` — 131 pages in the current build.

Institutional front matter (group members, supervisor, certificate, declaration,
dedication, acknowledgement, university branding) is **deliberately omitted**.
The front matter is a title page carrying the 10Pearls logo and the author's
name, a one-page abstract, and the automatic contents, figure and table lists.

## 2. How to compile

**Locally (MiKTeX / TeX Live already installed):**

```bash
latexmk -pdf main.tex
```

`latexmk` runs pdfLaTeX as many times as the contents, figure list, table list and
cross-references need. Without it, run `pdflatex main.tex` three times.

**On Overleaf:** upload a ZIP of this whole folder, set *Compiler = pdfLaTeX* and
*Main document = `main.tex`*, and press Recompile. Every package used
(`mathptmx`, `amsmath`, `titlesec`, `caption`, `xltabular`, `booktabs`,
`geometry`, `setspace`, `hyperref`, `listings`, `fancyhdr`, `enumitem`,
`microtype`) is standard.

The current build is clean: **0 errors, 0 unresolved references, 1 minor overfull
box.**

To regenerate the diagrams after editing an HTML source:

```bash
cd figures_src
python render.py          # writes high-resolution PNGs into ../figures/
```

To re-capture the dashboard screenshots (requires Playwright's Chromium):

```bash
cd figures_src
python screenshots.py                        # uses the deployed URL
python screenshots.py http://localhost:5173  # or a local dev server
```

`screenshots.py` grows the viewport to the page height rather than using a
stitched full-page capture, because the responsive charts re-measure on a resize
but are not redrawn for a stitched capture — a full-page screenshot clips the
forecast curve. It also drives the What-If sliders and runs a real simulation so
the figure shows a genuine result.

## 5. Inserting a figure

```latex
\fig{filename}{width-fraction}{Caption text.}{fig:label}
```

- `filename` — the image in `figures/`, without extension.
- `width-fraction` — width as a fraction of the text width (`1.0` = full width).
- The caption is rendered centred below the figure and numbered per chapter.
- Refer to it with `Figure~\ref{fig:label}`.

Table captions are left-aligned above the table. Wide tables use `xltabular` so
they break across pages instead of leaving a page half empty. Code excerpts sit
inside a `figure` float and are captioned **Figure x.y**, because the template
numbers only figures and tables — there is no separate "Listing" counter.

## 6. Formatting compliance

| Requirement | How it is met |
|---|---|
| Body: Times New Roman, 12 pt, 1.5 line spacing | `mathptmx` + `\documentclass[12pt]` + `\onehalfspacing` |
| Chapter title: 20 pt Bold, Title Case, centred | `titlesec` `\chapter` display format |
| Section (x.y): 14 pt Bold | `titlesec` `\section` |
| Subsection (x.y.z): 14 pt Regular | `titlesec` `\subsection` |
| Figure caption: centred, below the figure | `caption` package, `\fig` macro |
| Table caption: left-aligned, above the table | `caption` package |
| Full-text-width tables that break across pages | `xltabular` |
| Page number bottom-centre on every page | `fancyhdr`, with `plain` made identical |
| Auto contents, list of figures, list of tables | `\tableofcontents`, `\listoffigures`, `\listoftables` |

For the literal Times New Roman outline rather than the Times-equivalent, compile
with XeLaTeX and replace the font block in `preamble/format.tex` with:

```latex
\usepackage{fontspec}
\setmainfont{Times New Roman}
```
