# Pearls AQI Predictor - Project Report

This folder contains the final submission PDF and supporting report figures for
the Pearls AQI Predictor project.

## Contents

| Item | Description |
|---|---|
| `Pearls_AQI_Predictor_Project_Report.pdf` | 132-page project report covering the problem, data, ML model, MLOps pipelines, SHAP explainability, analytics dashboard, deployment, testing and evaluation |
| `figures/` | Architecture diagrams, EDA charts, evaluation charts, SHAP chart, and screenshots of all five dashboard views |

The dashboard screenshots cover Forecast, Analytics & SHAP, Model Evaluation,
Monitoring, and What-If. The root [README](../README.md) contains the GitHub
repository link, live deployed application, API link, setup instructions, and
project overview.

## Submission checklist

- Keep the PDF and `figures/` directory with the submitted project.
- Use the root README as the primary project guide.
- Confirm the live links in the root README resolve before submission.
